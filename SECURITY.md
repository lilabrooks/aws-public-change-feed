# Security policy

## Reporting a vulnerability

Send security reports through [GitHub private vulnerability reporting](https://github.com/lilabrooks/aws-public-change-feed/security/advisories/new).

Include the affected commit or release, a minimal reproduction, the expected impact, and any known containment steps. Keep credentials, Slack webhook URLs, tokens, customer identifiers, and private AWS details out of the report. Use synthetic values where a reproduction needs secret-shaped input.

Keep the report private until a fix and disclosure plan are agreed. Public GitHub issues are appropriate for ordinary defects that carry no sensitive security details.

## Supported version

Security fixes target the current `main` branch. This repository has no separately supported release branches.
